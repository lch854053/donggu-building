# P3 검색 상태·통계 해석 개선 및 검증

## 1. 증상 분석

기준 `main`은 P1/P2 머지 커밋 `845b6ee`이며 작업 시작 시 원격에 추가 커밋이 없고 작업 폴더도 깨끗했다. `AGENTS.md`, 조회·세대 검사·캐시·통계 렌더러 및 3개 수집기를 확인했다. 메뉴·조건·상세 선택이 메모리에만 있었고 URL/History/최근 검색의 공통 규약이 없었다. 하단은 `document.lastModified`를 표시했고, SGIS 거처종류 기준연도를 별도 주택 시계열의 끝연도로 단정했다.

2026-10-25 운영 정적 파일 4개를 실제 HTTP로 읽어 다시 확인했다. 빈집 파일은 **648원본 레코드, 기준일 2025-07-16**이었다. KOSIS 보관 자료는 **2025년 미거주주택 4,985호, 비율 11.1%**, 수집일 `2026-08-03T12:18:32.981Z`였다. SGIS 수집일은 `2026-08-03T12:18:45.136Z`; REB 수집일은 `2026-08-03T23:51:06.799Z`, 보관 월간 자료의 마지막 시점은 2026년 6월이다. 이 값은 조사 당시 관측값이지 UI에 고정하는 상수가 아니다.

## 4. 근본 원인

조건과 결과를 구분하는 상태 규약 및 복원 소유권이 없었다. 통계는 조사 기준시점·API 수집일·문서 배포일을 구분하는 지표별 메타데이터가 없었고, 서로 다른 API에 공통 연도를 적용했다. 조건만 직렬화하고 기존 P1 세대 검사 위에 복원 세대를 추가했으며, 미확인 메타데이터는 추정하지 않게 했다.

## 5. 구현 내용

### URL 규약

- `#q=` 뒤 UTF-8 URI 인코딩 JSON, **`v:1`**. 해시는 일반 HTTP 요청의 경로/쿼리·Referer에 실리지 않지만 공개 링크 자체에는 주소가 들어간다. 브라우저 기록·확장 프로그램 등으로부터 비밀 저장을 보장하지는 않는다.
- 공통 `search-state.js`가 인코딩·파싱·타입·범위·버전·메뉴별 허용 필드를 검증한다. 한글·줄바꿈·공백·특수문자·빈 문자열을 보존하고 DOM에는 `value/textContent` 또는 기존 이스케이프를 쓴다.
- **현재 메뉴의 상태만** 담는다. `menu`, `tab`, `f`(허용된 입력/필터), `pick`(선택 식별자·상세 탭·지도 출처), `sort/page`, 지도 `view`, 윤곽지도 `theme/shape`다. 기본 메뉴·하위 탭·전체 범위·체크 기본값·기본 정렬·1페이지·기본 테마/형태는 가능한 한 생략한다.
- API 응답·도형·API 키·인증정보·DOM·결과 목록은 저장하지 않는다. 알 수 없는 최상위/필터/선택 필드는 거부한다. 인코딩 시 기존 쿼리도 공유 링크에서 제거한다.
- `pick.id`: 상세는 대장 PK 우선, 없으면 동명+건물명 조합. 공동주택은 K-apt 코드, 지도 빈집은 P2 원본 레코드 ID, 지도 단지/필지는 가용한 K-apt 코드/PNU, 철거 항목은 필지·구분·세 날짜의 결정적 복합키다. **배열 인덱스를 공유하지 않는다.** 유일하지 않은 후보는 임의로 선택하지 않는다. 주소/필지/복합키가 영구 건물 식별자라는 의미는 아니다.
- 전체 URL **8,000자 상한**(URI 인코딩 후 길이). 초과하면 자르거나 일부만 복사하지 않고 JSON 대안을 안내한다. 조건 JSON은 **250,000바이트**까지, 일괄 입력 문자열은 최대 200,000자까지 검증하며 파일에도 조건만 담는다. 서버 저장소는 추가하지 않았다.
- 긴 파일 조건은 화면 메모리에서만 유지할 수 있고 URL/History/새로고침으로 복원된다고 주장하지 않는다. JSON을 다시 불러와야 하며 화면에 길이 오류를 표시한다.

1. [서남로 1 단건 상세 조건](https://donggu-building.vercel.app/#q=%7B%22v%22%3A1%2C%22tab%22%3A%22detail%22%2C%22f%22%3A%7B%22dInput%22%3A%22%EC%84%9C%EB%82%A8%EB%A1%9C%201%22%7D%7D)

### 자동·수동 실행과 복원

| 진입 | 실행 기준 |
| --- | --- |
| 명시한 공유 URL·조건 JSON | 주소가 있는 **단건 상세만 자동 실행**. 입력·필터가 유효하게 복원된 뒤 실행 |
| 일괄·동 단위 조건·공동주택·철거·빈집·일반지도 공유 링크 | **조건만 복원**, 사용자가 조회. 선택·정렬·페이지는 조회 완료 뒤 적용 |
| 윤곽지도·통계 | 정적 화면/지도 초기화. 대량 건축물 API 검색은 실행하지 않음 |
| 뒤로/앞으로 | 이전에 실행했던 단건, 특정 행정동 조회, 정적 빈집/조건검색 없는 지도를 정상 캐시와 함께 재실행 가능. **동구 전역·일괄은 수동** 유지 |
| 최근 검색 | 단건도 자동 실행하지 않고 **조건만 복원** |

메시지로 조회 필요 여부를 알린다. 선택이 사라졌거나 유일하지 않으면 기본 결과를 유지하고 안내한다. 부분/미완료 조회에서 선택을 못 찾으면 삭제라고 단정하지 않는다. 저장한 결과의 재생이 아니라 현재 자료에 대한 조건 재현이며, 결과 변경과 파싱·조건 복원 실패는 서로 다른 메시지다.

### History와 최근 검색

- 메뉴/하위 탭, 새 검색 실행, 상세 열기/닫기, 페이지 전환은 의미 있는 **pushState** 대상이다. 같은 상태의 중복 push는 하지 않는다. 검색 전/후의 `ran` 차이는 같은 URL이어도 하나의 실행 이력으로 구분한다.
- 필터 편집은 조회 뒤 첫 편집에서만 초안 이력을 나누고 이후 **replaceState**한다. 숫자 입력·슬라이더·지도 이동·스크롤마다 push하지 않는다. 정렬/테마/복원 완료·진행 완료도 replace한다. 지도 이동은 복사/다음 의미 있는 행동 시 현재 중심·줌을 캡처한다. 이동만 하고 즉시 새로고침하면 마지막 기록 시점의 위치로 복원될 수 있다.
- popstate에서 이력을 추가하지 않는다. 복원에는 별도 세대를 두고 새 탐색·검색·취소가 소유권을 가져가도록 했다. P1의 응답/페이지/상세 소유권 검사를 유지한다. 선택/지도 재생 중 애니메이션은 비활성화해 끝난 줌 이벤트의 역덮어쓰기를 막았다.
- 정렬/페이지·선택과 가능한 스크롤을 복원한다. 결과가 줄면 페이지를 실제 범위로 제한한다. 브라우저의 자동 스크롤 복원 대신 이력의 좌표를 사용하되, 바뀐 데이터/화면 높이에서는 정확한 픽셀 위치가 달라질 수 있다.
- 최근 검색은 `localStorage`의 **`donggu.recent.v1`, 최대 10개**, 동일 조건 중복 제거, 오래된 항목부터 제거. 현재 메뉴의 조건과 저장시각만 저장한다. 일괄조회 주소는 자동 저장하지 않는다. 주소 없는 기본 일괄 화면도 저장하지 않는다.
- 항목 삭제·전체 삭제 제공. 저장소 차단/용량 초과·잘못된 JSON·지원하지 않는 저장 상태는 조회를 막지 않는다. 최근 검색을 자동 실행하거나 명시적 URL 위에 덮어쓰지 않는다.
- Clipboard API 복사 성공/실패 안내. 불가하면 읽기 전용 링크 입력을 표시하고 선택하여 수동 복사를 제공한다. 인접 안내에 주소 포함 사실과 결과 변경 가능성을 표시한다.

### 통계 의미·시점

- 각 KOSIS/REB 지표와 SGIS 거처 구성에 쉬운 설명·대상·단위·지역·자료 기준시점·수집일·원본 갱신일·주기·제공기관·원본 링크·주의사항을 접은 설명으로 추가했다. 확인되지 않은 기준은 `확인 필요/미확인`이다.
- 빈집 화면과 통계에 짧은 공통 설명을 제공한다. 행정 원본 레코드(건), 총조사 미거주주택(호), SGIS 거주가구(가구), 필지를 혼용하지 않는다. 총조사에는 일시적 미거주도 포함하며 행정자료와 모집단·시점·단위가 달라 직접 차감/비율 계산하지 않는다. 동구 제공파일의 법정 조사 포함·제외기준 전체는 확인 필요로 남겼다.
- `document.lastModified` 사용을 제거했다. 서비스 배포일은 모르면 미확인이다. 수집일이 최근이라고 조사도 최근이라고 표시하지 않는다. 공식 최신 여부를 검증하지 않은 자동 최신/오래됨 판정 및 임의 임계값 경고는 추가하지 않았다.
- SGIS `housesummary`는 연도 지정 API가 아닌데 주택 시계열의 마지막 연도를 `summaryYear`로 저장했다. 현재 JSON의 수치/시계열/수집일은 보존하고 그 필드는 `null`, 기존 추정은 `legacyAssumedSummaryYear`로 분리했다. 이후 수집기도 기준연도를 임의로 연결하지 않는다.
- REB 공식 설명은 월간 지수의 2026년 7월 개편을 **2026.6=100**으로 안내한다. 그러나 보관된 6월 값이 100이 아니고 API 스냅샷에 기준 메타데이터가 없으므로 그 기준을 보관값에 그대로 붙이지 않았다. **보관 시계열의 지수 기준은 확인 필요**이며 공식 개편 안내와 구분한다.
- 천원 단위 원본 가격은 보존하며 원·만원 환산을 병기한다. 지수는 가격과 구분하고 다른 단위는 같은 차트 축에 섞지 않는다. 단위/표시 기간/시리즈명을 보완하고 KOSIS·REB 시계열 전체를 접근 가능한 수치표로도 제공한다. SGIS 거처별 값은 기존 텍스트로 제공한다. 원자료가 지원하지 않는 기간 선택·비교 기능은 추가하지 않았다.
- 세 수집기가 공통 정의와 출처·단위·수집일·자료시점 메타데이터를 다음 산출물에도 기록하도록 했다. 원본의 표 ID·단위·시계열·갱신일은 보존한다. 확인하지 못한 원본 갱신일/지수 기준은 수집 시각에서 추정하지 않는다.

### 남은 제한

- 물리 휴대전화·iOS Safari·실제 스크린리더·실서비스 네트워크 복원 부하는 검증하지 않았다. 모바일 에뮬레이션을 실기기 검증이라고 하지 않는다.
- 조건은 현재 자료에 재적용한다. 만료된 캐시는 정상적으로 외부 요청이 생길 수 있다. 전역/일괄 결과 자체와 스크롤의 픽셀 단위 재생은 지원하지 않는다.
- 지도 확대 범위는 화면 크기에 따른 기존 최소 줌·동구 경계 제한도 따른다. 다른 화면 크기에서는 허용 범위에 맞춰 보정될 수 있다.
- 원천 ID 없는 동명 조합·철거 복합키/PNU는 공급자 영구 건물 ID가 아니다. 속성 변경이나 다중 후보는 선택을 복원하지 못할 수 있고, 이를 삭제라고 단정하지 않는다.
- SGIS 거처종류의 정확한 조사연도, 보관 REB 시계열의 지수 기준, 동구 빈집 파일의 법정 포함기준 전체·최신 원천 제공 여부는 여전히 확인 필요다. 공식 포털 접근만으로 데이터 정의를 추정하지 않았다.
- 새 수집기 산출물 전체 실행은 하지 않았다. 현재 자료 수치 기반 렌더링·공통 메타데이터와 수집기 연결을 테스트했으며, 이후 원천 API의 필드 변경까지 검증한 것은 아니다.

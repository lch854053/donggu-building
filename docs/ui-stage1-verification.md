# UI 개선 1단계 — 구현·검증 기록

## 1. 증상 분석

- 기준: `a724f8e` (P3 PR #66 머지). 작업 시작 시 `AGENTS.md`와 최신 코드를 읽고 `git fetch`로 원격 추가 커밋 없음·작업 폴더 깨끗함을 확인했다.
- 실제 브라우저의 수정 전 360px 화면에서 공유 도구 상단은 208px, 기본 일괄 검색 입력은 약 614px였다. 공유·파일 선택·최근 검색이 검색보다 앞에 있었다.
- 취소 버튼은 조회 여부와 무관하게 생성됐다. 메뉴 `aria-current`는 클릭에서만 갱신됐으며 복원 함수가 직접 메뉴를 바꾸면 이전 값을 유지할 수 있었다. 복사 성공 메시지는 만료되지 않았다.
- 서남로 1의 실제 운영 `/api/building` 응답(2026-10-25, 전체 필지 파라미터 사용)은 3행: 부속건축물 44.78㎡, 주건축물 11,751.74㎡, 주건축물 제2동 5,920.75㎡였다. 첫 항목을 선택하는 현재 코드가 부속건축물을 먼저 표시했다.

## 4. 근본 원인

보조 도구가 화면 의미와 무관하게 검색 앞에 고정돼 있었다. 조회 수명주기·현재 화면·사용자 알림을 각각 추적하지 않았으며, 상세 기본 선택은 주/부속 구분을 적용하지 않았다. 기존 데이터·URL 키는 유지하고 표시·활동 상태·대표 선택 경계만 보완했다.

## 5. 수정 내용

### 검색 우선 배치·표현

- 공통 서비스명 **동구 건축물 정보**, 현재 화면 제목과 한 줄 설명 및 화면별 브라우저 제목을 추가했다.
- 건축물 하위 메뉴는 **주소로 찾기 / 여러 주소 한 번에 / 조건으로 찾기**. 내부 `detail/bulk/cond` 및 API/URL 형식은 그대로다.
- 순서: 서비스 메뉴·하위 메뉴 → 현재 화면 제목 → 입력·조건 → 작은 보조 도구 → 결과. 검색에 앞서 큰 공유 영역을 표시하지 않는다.
- **공유** 버튼은 검색 카드 바로 아래에 배치했다. 지도는 고정 높이 사이드바 안에 도구를 넣으면 결과가 잘릴 수 있어 지도 결과 영역 바로 뒤에 배치했다. 통계에서는 조건 파일 메뉴를 표시하지 않고 작은 공유·최근 검색만 유지한다.
- **검색 조건 저장·불러오기**를 접힌 메뉴로 제공한다. 화면에서는 ‘조건 파일 저장/불러오기’로 표시하고 JSON 설명은 메뉴 안에 둔다. 원래 파일 입력은 `hidden`, 한글 버튼이 파일 선택을 연다. 저장·불러오기 및 기존 파일 형식은 유지한다.
- 주소 포함 안내는 공유할 때 버튼 근처에, 조건 파일 도구를 펼치면 해당 도구 안에 표시한다. 최근 검색은 작고 접힌 메뉴지만 같은 도구 줄에서 찾을 수 있다.

### 기본 화면·URL 호환

- 상태 없는 새 방문만 **주소로 찾기**다. HTML 초기 표시도 상세 화면이라 일괄 화면이 먼저 나타나는 과도기를 줄였다.
- 명시한 공유 URL 또는 이력 상태가 우선한다. **v1의 탭 생략은 여전히 bulk**로 해석한다. `{"v":1,"f":{"input":"서남로 1"}}`의 의미를 변경하지 않았다.
- 최근 검색은 기존 브라우저 저장 형식을 그대로 읽고 한글 라벨만 생성한다. 최대 10개·중복 제거·일괄주소 자동 저장 제외·개별/전체 삭제·조건만 수동 복원 정책은 그대로다.
- 예: `서남로 1 · 건물 상세`, `계림2동 · 빈집 지도`, `계림2동 · 철거·멸실 조회`, `동구 전체 · 빈집 조회`. 지도 기본 소스가 생략됐으면 기존 규약의 빈집·공동주택을 반영하며 명시한 복수 소스도 짧게 표시한다. 범위/종류/미확인 포함/정렬/페이지 등 저장된 추가 조건을 요약해 같은 지역의 다른 조건을 구분한다.
- 긴 라벨은 화면에서 말줄임하되 전체 문자열을 `title`과 `aria-label`에 제공한다. 제목 생성 때문에 저장 기록이나 상태 키를 변경하지 않는다.

### 취소·메시지·접근성

- 비동기 조회 실행 티켓을 추적한다. 시작에만 취소 버튼을 표시하며 완료/오류/취소/초기화/탐색 교체 뒤 숨긴다. 이전 실행의 finally가 새 실행 상태를 지우지 않도록 티켓을 비교한다.
- 기본 대장 카드 표시 후 GIS/대지권 보강만 진행 중이면 **보강정보 조회 취소**로 표시한다. 보강 재시도의 로딩 상태도 반영한다. 초기화는 기존 보조 버튼 스타일로 유지한다.
- 복사 성공은 **4초** 후 만료된다. 화면 전환 시 공유 메시지·수동 복사 입력·열린 도구를 초기화한다. 수동 복사와 오류/부분 조회/조건 변경 안내에는 성공 알림용 자동 만료를 적용하지 않는다.
- 메시지마다 revision을 갱신하고 이전 타이머를 취소한다. 늦게 끝난 클립보드 작업도 화면 소유권·메시지 revision을 확인하므로 새로운 실패 안내나 다른 화면을 덮지 않는다.
- 화면 전환 함수에서 시각적 `active`, `aria-current`, 하위 메뉴 `aria-pressed`, 제목을 함께 갱신한다. 클릭뿐 아니라 URL·최근 검색·뒤로/앞으로·새로고침도 같은 경로를 사용한다. 상세 동 선택에도 `aria-pressed`를 반영한다.
- 접힌 메뉴는 네이티브 `details/summary`로 키보드 조작 가능하며 `aria-expanded`를 동기화한다. 최근 검색/파일 복원 뒤에는 현재 검색 입력으로 포커스를 옮기고, 이전 복원의 늦은 완료가 포커스를 빼앗지 않게 소유권을 검사한다. 상태 안내의 `role=status/aria-live=polite`는 유지한다.

### 주건축물 기본 선택

- 새로운 `pickDetailTitle()`은 **입력한 특정 동 → 명시된 주건축물 후보 → 안전한 기존 대표/첫 행** 순서로 선택한다. 주건축물 후보 안에서는 기존 `pickMainTitle()`의 용도·안정 순서 기준을 재사용한다. 면적 비교는 하지 않는다.
- 공유·이력의 명시적 식별자 선택은 P3의 로딩 후 복원 단계에서 적용되어 입력 동·기본값보다 우선한다.
- `D_DONGS`의 기존 정렬과 원본 객체, 버튼 인덱스 및 공유 ID를 유지한다. 부속건축물도 그대로 선택할 수 있다. 주건축물 용도 공백을 이유로 부속건축물을 먼저 고르지 않는다.
- 응답에 있는 숫자형 대장 PK의 정밀도 문제까지 교정하는 작업은 하지 않았다. 기존 P3 식별자 규약을 바꾸지 않는 이번 범위의 제한이다.

재현:

```bash
node --test
git diff --check
# 정적 브라우저 테스트 서버: python3 -m http.server 3000
PLAYWRIGHT_MODULE=/absolute/path/playwright/index.mjs node scripts/ui-stage1-browser.mjs after
EVIDENCE_TAG=ui-stage1-compat PLAYWRIGHT_MODULE=/absolute/path/playwright/index.mjs node scripts/p2-ui-regression.mjs
EVIDENCE_TAG=ui-stage1-p3 PLAYWRIGHT_MODULE=/absolute/path/playwright/index.mjs node scripts/p3-browser-regression.mjs
PLAYWRIGHT_MODULE=/absolute/path/playwright/index.mjs node scripts/p2-race-regression.mjs
```

기본 실행 파일은 macOS Brave이며 다른 Chromium은 `CHROMIUM_PATH`로 지정한다. Playwright는 기존 별도 도구 디렉터리를 사용했고 운영 의존성은 추가하지 않았다. 수정 전 캡처는 수정 전 커밋을 별도 서버로 제공해 `BASE_URL=...`과 `before` 인자로 재현할 수 있다.

### 남은 제한

- 모바일은 **Chromium 터치 에뮬레이션**이며 물리적 iOS/Android·Safari·스크린리더 실기는 검증하지 않았다.
- 브라우저 검사들을 동시에 실행했을 때 초기화/시간초과 실패가 있어 직렬로 재검증했다. 해당 병렬 실패의 원인은 확정하지 않았으며 병렬 실행 안정성을 보장하지 않는다. 지도 도구의 사이드바 간섭은 별도로 재현·수정하고 해당 테스트를 재통과했다.
